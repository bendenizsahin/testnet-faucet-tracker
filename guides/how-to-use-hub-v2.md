# How to Use RurouniYu Hub V2

A guide to using the RurouniYu Hub V2 DApp on all supported testnets.

## Link
[rurouniyuhub-v2.vercel.app](https://rurouniyuhub-v2.vercel.app/)

## Supported Chains
- Robinhood Testnet
- ARC Testnet
- INK Sepolia
- GIWA Sepolia

## Features

### Daily GM
- Click "Say GM" every day to build your streak
- Resets at 00:00 UTC+3
- Each GM = 1 onchain TX

### Minesweeper
- Reveal mines on-chain
- Each revealed field = 1 TX
- Claim score after game

### NFT Minting
- Mint $CHECKmate NFT
- Max 9999 per chain
- Each mint = 1 TX

### Create NFT
- Mint your own custom NFT
- Upload image via IPFS (Pinata)
- Each mint = 1 TX

### Deploy Logger
- Log your contract deployments on-chain
- Each log = 1 TX

### Games
- Play Tetris, Flappy Bird, Chev Chess
- Claim score on-chain after game
- Each claim = 1 TX

## Tips
- Switch chains using the dropdown in the header
- Click "Faucet" button to get testnet tokens
- Check your stats in the Profile tab
