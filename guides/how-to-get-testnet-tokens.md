# How to Get Testnet Tokens

A step-by-step guide to getting testnet tokens for each supported chain.

## ARC Testnet
1. Go to [faucet.circle.com](https://faucet.circle.com/)
2. Connect your wallet
3. Select ARC Testnet
4. Request tokens

## INK Sepolia
1. Go to [inkonchain.com/faucet](https://inkonchain.com/faucet)
2. Connect your wallet
3. Request tokens

## Robinhood Testnet
1. Go to [faucet.testnet.chain.robinhood.com](https://faucet.testnet.chain.robinhood.com/)
2. Connect your wallet
3. Request tokens

## Base Sepolia
1. Go to [docs.base.org/faucets](https://docs.base.org/base-chain/network-information/network-faucets)
2. Choose a faucet provider
3. Connect your wallet
4. Request tokens

## GIWA Sepolia
1. Go to [faucet.giwa.io](https://faucet.giwa.io/#/)
2. Connect your wallet
3. Request tokens
