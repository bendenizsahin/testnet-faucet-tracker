# How to Use RYU Swap & Bridge

A guide to using the RYU Swap & Bridge DApp.

## Link
[rurouniyu-swap.vercel.app](https://rurouniyu-swap.vercel.app)

## Features

### Swap
- Swap tokens on ARC Testnet
- Powered by onchain liquidity

### Bridge (CCTP)
- Bridge USDC between ARC Testnet and Base Sepolia
- Powered by Circle CCTP V2
- Cross-chain in minutes

## How to Bridge
1. Go to [rurouniyu-swap.vercel.app](https://rurouniyu-swap.vercel.app)
2. Connect your wallet
3. Select "Bridge" tab
4. Choose source chain (ARC Testnet)
5. Choose destination chain (Base Sepolia)
6. Enter amount
7. Click "Bridge"
8. Confirm transaction in wallet
9. Wait for CCTP confirmation

## Tips
- Make sure you have testnet USDC on ARC
- Get USDC from [faucet.circle.com](https://faucet.circle.com/)
- Bridge takes a few minutes to complete
